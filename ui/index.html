Create a credential with ordinary REST access in Kata.fit's external Coach settings. Older credentials must be replaced to use Dashboard and ordinary reads; denied reads do not fall back to MCP.

Models

Providers must offer an OpenAI-compatible Chat Completions API: Coach sends requests to the base URL plus /chat/completions. Coach does not discover, list or verify models; enter model IDs exactly as your provider documents them. Browsing and editing here contacts nobody. Save applies the selected model; Preview, the worker and native Operator Pi use the saved active model.

API keys are stored privately and never shown again. Changing a provider's base URL requires re-entering its key or removing it. A remote provider receives Coach requests and any data included in them; original images are sent only when the saved active model has vision enabled.

Skills

Skills are optional workflows. Purpose and triggers guide Operator matching; background typed tasks use the default skill mapping, and member requests use fixed keyword relevance rules. Editable trigger text does not control background routing or guarantee selection. Skills are guidance, not permission: backend authorization, audience and tool schemas remain authoritative. Keep reusable guidance only; never paste member/customer evidence or credentials into a skill.

If another tab changed Skills, refresh to keep your drafts and review the latest saved values below. Nothing is retried automatically; review before choosing Save skill again.

Backend performance

              

                All retained backend receipts, independent of log level.
                Cumulative request time is not wallclock time: overlapping
                requests add together. This is not lifetime usage; the
                20,000-entry window also includes other logs.
              

              

              

                
                
              

              

                How metrics are calculated
                

                  Durations use measured calls only; missing durations are not
                  zero. p95 uses nearest rank (small samples under 20 can
                  mislead); median uses the midpoint. Outcome rates use all
                  calls, including unknown outcomes. Failed time includes
                  timeouts and other failures, not cancellations.
                

              

              

                Select a call to inspect receipts. Scroll the breakdown for more
                calls.
