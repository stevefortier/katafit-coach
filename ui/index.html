Backend performance

            

              All retained backend receipts, independent of log level.
              Cumulative request time is not wallclock time: overlapping
              requests add together. This is not lifetime usage; the 5,000-entry
              window also includes other logs.
            

            

            

              
              
            

            

              How metrics are calculated
              

                Durations use measured calls only; missing durations are not
                zero. p95 uses nearest rank (small samples under 20 can
                mislead); median uses the midpoint. Outcome rates use all calls,
                including unknown outcomes. Failed time includes timeouts and
                other failures, not cancellations.
